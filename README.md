# The Atlas of Systemic Intelligence

Welcome to **The Atlas of Systemic Intelligence**, a rigorous catalog of cross-domain leverage principles filtered for four core properties:
1. **Well-supported by evidence**
2. **Counterintuitive**
3. **Generalizable across domains**
4. **High-return for the effort of applying them**

This repository Restructures strategic models into the **From Abstraction to Implementation** methodology. Each mechanism is mapped to one of the deepest recurring control classes and systematically answers the **Five Questions** of system design along with **Six Practical Output** criteria.
